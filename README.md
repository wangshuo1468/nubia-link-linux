# 已实现

更新：2026-10-14。已测试手机：NX721J / Android 15 / NebulaAIOS 1.0.17。其他机型、ROM 及未完成部分见 [未实现.md](未实现.md)。

## 连接与界面

- 默认进入多屏协同，开启接收；由手机自动发现电脑并发起连接，电脑自动接通，无需扫码、ADB 或电脑确认。
- 智慧投屏与多屏协同使用独立发现、关联和媒体会话，不先连接智慧投屏再建立协同。
- 两个模式在同一主窗口切换，自动停止旧模式接收并开启目标接收，无需先点暂停；协同手机断开后继续接收，手动暂停保持暂停。
- 关闭主窗口会停止会话并退出，不驻留托盘。
- 专注画面隐藏操作面板，保留系统标题栏与边框，支持拖动、按比例缩放和 Esc 返回。进入专注及横竖切换时居中，同方向保留手动位置、尺寸。

## 智慧投屏：手机“搜索设备”入口

- Lelink v1 自动发现、连接、H.264 视频接收与渲染。
- 原厂 AAC-ELD 声音接收、电脑播放、静音与恢复。
- 手机正常断开、电脑断开后保留发现及再次连接出画面和声音。
- 去除视频编码画布内的成对外围黑边，带标题栏的横竖窗口已实机验证。
- 最新尺寸稳定逻辑已实现：累计 15 帧确认方向和边界、按方向缓存边界、首次连接等待校准。同方向不随深色页或短暂弹窗反复调整窗口。此修复通过离线回归，修复后的手机旋转尚待实测。

此入口的电脑反控尚未实现。

## 多屏协同

- 原厂 BLE 广播、GATT 扫描、RFCOMM 服务管理关联及手机主动连接。
- 手机主屏镜像，H.264 视频、Opus 声音及电脑输出。
- 原厂鼠标点击、返回键、专用文字框中文输入；设置搜索已实测。
- 在同一协同身份内从镜像切换到 virtualDisplay 独立应用，不借用智慧投屏会话。
- 设置应用的独立画面、鼠标、中文搜索及正常退出已实测，手机主屏可保持桌面。当前一次一个已在手机打开过的应用。

其他应用、手机主屏同时操作另一个应用、远程启动和多应用并行尚未完成验收。

## 文件互传与开发诊断

- 独立原厂 DFS 目录浏览、普通单文件上传和下载；中文名称及分块往返内容一致性已实测。
- 文件窗口关闭时发送原厂退出消息并清理本机连接。
- 保留命令行 RMCast 局域网及已授权 ADB 入口，其画面、声音、基础鼠标、HOME 和中文输入已有实测；这些控制能力不适用于 Lelink 搜索入口。
- 实机测试和协议探针源码保留，默认不构建，分别用 BUILD_DEVICE_TESTS、BUILD_PROTOCOL_PROBES 按需启用，不注册到自动 CTest。

## 验证与开源基础

- C++17 / Qt 6 / FFmpeg 原生客户端，无数据库。已验证环境为 Ubuntu 26.04.1、Qt 6.10.2、FFmpeg 8、BlueZ 5.85。
- 清理后的 14 项离线回归全部通过；源码包已完成独立 Release 构建和安装验证，关闭测试后不依赖 Qt Test。离线测试不替代手机功能验收。
- 音频测试样本为项目生成的 24 秒、44.1 kHz 双声道 440 Hz 正弦音，经 NX721J 原厂 Lelink 编码后截取 40 帧；每帧为 4 字节小端长度和裸 AAC-ELD 数据，不含用户录音、媒体、设备标识或网络头。
- 项目自有代码采用根目录 Apache License 2.0。QtScrcpy 渲染器和 libcoap 的来源、修改声明及许可证保留在 third_party；系统 Qt、FFmpeg、libbluetooth 依各自实际构建许可证使用，不能统一视为 Apache 2.0。
